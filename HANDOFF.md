## Key Gotchas

- **Freerouting is deterministic** — same DSN produces byte-identical SES. Don't increase `-mp` beyond 15 (won't finish in 300s).
- **Every pre-route change reshuffles freerouting's result** — trades one stuck net for another. Iterate empirically.
- **`route` skips `populate`** — layer count, EP-net, or footprint changes need the full pipeline or `setup` then `route`.
- **DRC nondeterminism** — KiCad's connectivity cache can cause phantom unconnected items. Fix: load PCB → save → run DRC.
- **Custom footprints** in `hardware/footprints/autofeeder.pretty/`, stock from `/usr/share/kicad/footprints`.
- **Requires**: kicad-cli, java, `/opt/freerouting.jar`.
